# Libre AI Model Policy

Comprendre si un usage prévu d’un modèle d’IA respecte les règles de votre organisation, et pourquoi. Ce produit vise les personnes qui choisissent des modèles ou examinent leur utilisation et ont besoin d’une décision expliquée plutôt que d’un simple oui ou non.


## Usages visés

- Comparer un usage envisagé à des règles explicitement approuvées.
- Identifier les conditions à remplir avant de pouvoir accepter cet usage.
- Voir quelles informations sur le modèle manquent, sans transformer l’incertitude en accord.

**Aujourd’hui :** le code et les tests sont présents ; leur intégration locale est en cours. Le [guide de développement](docs/DEVELOPMENT.md) décrit l’installation et les vérifications.
