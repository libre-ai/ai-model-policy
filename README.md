# Libre AI Model Policy

Understand whether a proposed use of an AI model fits your organization's rules, and why. This product is intended for people choosing models or reviewing their use who need an explained decision rather than an unexplained yes or no.


## Intended uses

- Compare a planned use with an explicitly approved set of rules.
- Identify conditions that must be met before that use could be accepted.
- See which model facts are missing instead of treating uncertainty as approval.

**Today:** this repository documents the proposed product; no usable application is available here yet.
